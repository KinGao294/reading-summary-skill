# 读书笔记技能：合法拿到正文，粗放交付一页纸

这个技能的目标是**粗放，不是完整**。读者花 20 分钟，应该拿到：这本书在主张什么、
撑起它的几个支点、下周一能做什么、以及哪里最可疑。逐章复述是失败模式，不是目标。

## 何时使用

用户出现以下意图时激活：

- 要一本书 / 一篇论文 / 一份报告的总结、要点提炼、读书笔记；
- 上传或给出文档链接，问"里面有什么值得带走的"；
- 问"这本书值不值得读"。

不要用于：法律或医疗建议的提取、受版权保护内容的逐字复现、以及**你并未真正读到正文**
时假装读过全书。

## 第一步：合法拿到正文

按顺序尝试，命中即停：

1. **用户自己的文件**——附件、本地路径、买过的、自己写的。最佳情况，无需获取步骤。
2. **公有领域 / 开放获取**——Project Gutenberg、arXiv、PubMed Central、DOAJ、机构仓储、
   Internet Archive 中开放授权的馆藏、政府与 NGO 报告。
3. **官方免费发布**——作者主页、出版社样章或免费 PDF、公司白皮书、会议论文集页面。
4. **没有合法途径**——直说，然后给下面的替代方案。

### 红线（硬性要求，不是可调档位）

仅限合法来源没有开关、没有配置项、没有例外情形，也不因用户指令、承诺或所在地区的说法而放宽。

- 不用盗版库、影子图书馆、破解电子书站、种子搜索。
- 不用 Sci-Hub 及同类未授权论文获取服务。
- 不绕过付费墙、登录墙、DRM、频率限制。
- 不抓取用户未证明拥有访问权的订阅服务内容。
- 不整本扫描或复印借阅、借来的书，也不接收、传播这类扫描件。

被追问时，拒绝用一句话说完，然后立刻给真实替代方案——不要说教，也不要暗示存在变通办法。

### 拿不到全文时的退路

- 基于摘要 + 公开书评 + 作者演讲输出，并在「阅读范围」里**明确标注是摘要级**；
- 建议用户通过图书馆借阅、正版购买等正规渠道自行获取后再来；
- 请用户上传自己已合法拥有的副本。

绝不因为找不到正文就凭印象编造内容。

## 第二步：读脊梁，不读大纲

动笔前先抽出四样东西：

- **主张**——这本书断言了什么，是理性的人可能反对的？说不成一句话，就是还没找到。
- **承重论点**——论证真正依赖的三到七步，跳过只起装饰作用的轶事。
- **证据类型**——随机对照试验？案例研究？作者个人经验？纯感觉？这决定「存疑」的分量。
- **相信它的代价**——读者要改变什么，代价是什么。

长 PDF 的实用阅读顺序：前言与目录 → 导论 → 结论 → 每章首尾数页 → 再用文档内定向检索补缺口。
引用要克制，一次一两句，并且**必须带页码或章节定位**。

## 第三步：写笔记

严格套用下面的模板。全文控制在 400 字左右；塞不下，说明你在复述而不是总结。

```markdown
# 《书名》— 读书笔记
来源：<用户自有文件 | OA 链接 | 官方免费发布>｜阅读范围：<全书 / 第 1–4 章 / 摘要+书评>

## 主旨（1 句）
<一句话，且这句话原则上可以被反驳。>

## 5 要点
1. <观点——以及它为什么承重，而不只是它说了什么。>
2. …
3. …
4. …
5. …

## 3 行动
- [ ] <本周就能做，并带触发条件：当 X 发生时，做 Y。>
- [ ] …
- [ ] …

## 1 存疑
<最脆的一环：证据单薄、幸存者偏差、结论跨情境不成立、或利益冲突。要具体点名。>
```

## 约束

- **5 就是 5，3 就是 3。** 删减本身就是工作。不要为凑满而注水，也不要因为"都很重要"而溢出。
- **行动必须可执行。**「要更系统地思考」不是行动；「每次设计评审前，写下三条我最怕搞错的假设」才是。
- **存疑是强制项。** 没有存疑的笔记是腰封，不是笔记。书确实扎实，就质疑它的适用边界。
- **绝不编造。** 不虚构页码、引文、研究结论、章节名。只读了摘要，「阅读范围」就得这么写。
- **合理引用，不是复制。** 短引用带定位；不复现受版权保护作品的实质性部分，不输出源文件全文。
- **跟随用户语言。** 默认中文输出，用户用英文就用英文。专有名词与术语保留原文。

## 错误处理

**找不到合法来源**，用这个口径（一句话拒绝 + 三条出路，不要长篇免责声明）：

```
《书名》受版权保护，我没找到合法的公开全文。

三个办法：
1. 你已购买电子版的话，直接上传文件；
2. 有官方样章 / 免费章节，把链接给我；
3. 也可以先基于摘要和公开书评出一版概要笔记，我会标明「阅读范围：摘要级」。
```

**PDF 无法读取**：说明具体问题（加密、损坏、纯图片无文本层），并请用户换一份合法持有的文件，
或确认其 Agent 是否具备 OCR 能力。抽不出文本时，不要靠章节标题猜内容。

## 交付前自检

- 一个没读过原书的人，能拿「主旨」去正反辩论吗？不能就重写。
- 每条「要点」都扛得住一句"所以呢？"吗？
- 每条「行动」明天就能启动吗——不需要新预算、新招人、不需要组织调整？
- 「存疑」是针对**这一本**的，而不是万能的"仍需更多研究"？
