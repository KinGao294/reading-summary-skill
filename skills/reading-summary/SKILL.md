# 图书总结技能 (Reading Summary Skill)

## 技能描述

本技能用于生成结构化的图书阅读笔记。Agent 将首先获取合法的 PDF 文件，然后生成包含主旨、要点、行动项和疑问的粗放式读书笔记。

**核心流程：**
1. 先获取合法的 PDF 文件（公开资源或用户提供的文件）
2. 生成结构化笔记，包含：
   - 1 个核心主旨
   - 5 个关键要点
   - 3 个可行动项
   - 1 个批判性疑问

## 使用场景

当用户请求以下任务时激活本技能：
- "帮我总结这本书"
- "生成这本书的读书笔记"
- "分析这个 PDF 的核心观点"
- "给我这本书的要点提炼"

## 合法性政策（红线规则）

本技能**默认严格遵守合法性要求**，仅支持以下来源：

✅ **允许的来源：**
- 公有领域（Public Domain）的 PDF
- 作者或出版商官方发布的免费资源
- 开放获取（Open Access）出版物
- 用户自己拥有的文件或附件
- 用户通过合法渠道购买并提供的电子书

❌ **明确禁止的来源（默认红线）：**
- 盗版网站（如 Z-Library、Library Genesis 等）
- 破解或去除 DRM 的电子书
- 绕过付费墙的技术手段
- Sci-Hub 或类似的未授权访问服务
- 任何侵犯版权的下载途径

**重要：** 在处理任何 PDF 之前，Agent 必须首先验证来源的合法性。如果无法确认合法性，应拒绝处理并向用户说明原因。

## 工作流程

### 1. 获取 PDF 文件

**优先顺序：**

a) **用户直接提供文件**
   - 检查用户是否上传了 PDF 附件
   - 验证文件格式和可读性

b) **搜索合法的公开资源**
   - Google Scholar（开放获取论文）
   - arXiv.org（预印本论文）
   - Project Gutenberg（公有领域图书）
   - 出版商官方网站的免费章节/样章
   - Internet Archive（公有领域资源）

c) **请求用户提供**
   - 如果无法找到合法来源，礼貌地请求用户提供：
     - 购买的电子书文件
     - 图书馆借阅的扫描件
     - 作者或出版商授权的副本

**禁止操作：**
- 不得从盗版网站下载
- 不得使用破解工具
- 不得绕过付费墙
- 不得使用 Sci-Hub（除非用户明确说明其所在地区合法）

### 2. 生成结构化笔记

成功获取合法 PDF 后，按以下格式生成笔记：

```markdown
# 《[书名]》读书笔记

## 📖 核心主旨（1个）

[用 2-3 句话概括本书的核心论点或主要观点]

## 🔑 关键要点（5个）

1. **[要点标题]**: [详细说明，2-3 句话]

2. **[要点标题]**: [详细说明，2-3 句话]

3. **[要点标题]**: [详细说明，2-3 句话]

4. **[要点标题]**: [详细说明，2-3 句话]

5. **[要点标题]**: [详细说明，2-3 句话]

## 💡 可行动项（3个）

1. **[行动项标题]**: [具体可执行的建议，如何应用书中的观点]

2. **[行动项标题]**: [具体可执行的建议，如何应用书中的观点]

3. **[行动项标题]**: [具体可执行的建议，如何应用书中的观点]

## ❓ 批判性疑问（1个）

**[疑问标题]**: [对书中某个观点的质疑或需要进一步探讨的问题，展现批判性思维]

---

**笔记生成时间**: [时间戳]
**来源**: [合法来源说明]
```

### 3. 输出规范

- 使用清晰的中文表达
- 保持结构化格式
- 要点应具体且可操作
- 批判性疑问应有深度
- 标注 PDF 来源以证明合法性

## 错误处理

### 无法获取合法 PDF

当无法找到合法来源时，使用以下模板回复用户：

```
很抱歉，我无法找到《[书名]》的合法公开 PDF 资源。

为了生成读书笔记，您可以：
1. 如果您已购买此书的电子版，请上传 PDF 文件
2. 如果此书有官方免费样章，请提供官方链接
3. 如果此书在公有领域，请提供 Project Gutenberg 或 Internet Archive 的链接

我遵守版权法规，不能从盗版网站或通过非法手段获取内容。感谢理解！
```

### PDF 损坏或无法读取

```
PDF 文件存在问题：[具体错误]

请尝试：
1. 重新上传文件
2. 确认文件未加密或损坏
3. 提供其他格式的文件（如果可能）
```

## 配置选项

本技能可通过以下环境变量或配置文件自定义：

```yaml
# 可选配置（高级用户）
reading_summary:
  output_language: "zh-CN"  # 输出语言，默认中文
  format: "markdown"         # 输出格式
  strict_legal_mode: true    # 严格合法模式（推荐保持开启）
  max_file_size: "50MB"      # 最大文件大小
```

## 限制说明

1. **文件大小**: 建议 PDF 文件不超过 50MB
2. **语言支持**: 主要支持中英文 PDF
3. **质量依赖**: 笔记质量取决于 PDF 的文本可提取性（扫描版 PDF 可能效果较差）
4. **版权责任**: 用户对提供的 PDF 合法性负责
